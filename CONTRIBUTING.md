# Contributing

Contributions are welcome through pull requests.

1. Fork the repository.
2. Create a branch in your fork.
3. Commit and test your changes.
4. Open a pull request against `main`.

Direct pushes to `main` are not permitted. Opening a pull request does not grant permission to merge it; the repository owner retains final approval and merge rights.

Do not include credentials, tokens, private keys, personal data, or other secrets in commits, issues, or pull requests.

# omarchy-advanced-clipboard

Advanced clipboard tooling for Omarchy.

## Contributing

The repository is public and may be cloned or forked. The default branch is protected:

- direct pushes and force-pushes to `main` are blocked;
- changes must be proposed through a pull request from a fork;
- only the repository owner can approve and merge changes.

See [CONTRIBUTING.md](CONTRIBUTING.md) and [SECURITY.md](SECURITY.md).
